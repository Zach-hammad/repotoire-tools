# Contributing

Start with a bounded [issue or patch proposal](https://github.com/Zach-hammad/repotoire-tools/issues). Describe the intended behavior, owned paths, dependency changes, compatibility impact, and checks. Include a small reproduction for a defect and avoid sensitive repository contents. Follow the [checker](docs-checker/CONTRIBUTING.md) or [skill](organized-chaos/CONTRIBUTING.md) guidance for the affected component.

Zacharia Hammad is the maintainer and owns repository integration into primary `main`. Writers implement an approved scope; the maintainer checks the fixed result and verification evidence before acceptance. Run relevant local checks and record exact commands, results, source hashes, and unavailable checks. Releases are manual; this repository has no automatic CI requirement.

Submit only material you have the right to contribute. Unless explicitly stated otherwise, contributions intentionally submitted for inclusion are under Apache-2.0 as described in [LICENSE](LICENSE), section 5. Preserve copyright attribution and third-party terms and notices.

Use [private vulnerability reporting](SECURITY.md) for security defects. Keep credentials, private configuration, build output, unrelated product code, and repository history outside a proposed source change.
