# Security reporting

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Zach-hammad/repotoire-tools/security/advisories/new). Zacharia Hammad maintains this repository. Include the affected component, version or source revision, expected and observed behavior, and a minimal reproduction using synthetic data. Describe the impact and any suggested correction. Do not include tokens or private repository contents.

Keep unpatched vulnerability details out of public issues and examples while the report is assessed. No response or remediation schedule is guaranteed. Local test results do not establish a general security clearance, provider readiness, or cross-platform qualification.

The [checker security boundary](docs-checker/SECURITY.md) covers untrusted repository files and bounded subprocess observations. The [skill security boundary](organized-chaos/SECURITY.md) covers private configuration, untrusted model responses, and artifact verification. Review the applicable boundary before reporting or changing behavior.
